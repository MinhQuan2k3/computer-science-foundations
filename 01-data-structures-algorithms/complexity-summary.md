# Complexity Summary

| Topic | Typical operation | Time |
|---|---|---:|
| Array | Index access | O(1) |
| Array | Search | O(n) |
| Singly Linked List | Search | O(n) |
| Singly Linked List | Insert at head | O(1) |
| Stack | Push/Pop/Top | O(1) |
| Queue | Enqueue/Dequeue/Front | O(1) |
| Hash Table | Get/Put/Remove average | O(1) |
| BST | Search/Insert average | O(log n) |
| BST | Search/Insert worst | O(n) |
| Graph adjacency list | BFS/DFS | O(V + E) |
| Bubble Sort | Sort | O(n²) average/worst |
| Selection Sort | Sort | O(n²) |
| Insertion Sort | Sort | O(n²) average/worst |
| Merge Sort | Sort | O(n log n) |
| Quick Sort | Sort | O(n log n) average; O(n²) worst |
| Linear Search | Search | O(n) |
| Binary Search | Search | O(log n) |
