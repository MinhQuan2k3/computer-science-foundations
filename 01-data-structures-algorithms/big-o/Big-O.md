# Big O Complexity

Big O describes how an algorithm's resource usage grows as input size `n` grows.

## Common complexities

| Complexity | Example |
|---|---|
| O(1) | Array index access |
| O(log n) | Binary search |
| O(n) | Linear search |
| O(n log n) | Merge sort |
| O(n²) | Bubble sort |
| O(2^n) | Naive recursive subset generation |

## What to record

For every algorithm, consider:

- Time complexity: best / average / worst when meaningful.
- Auxiliary space complexity.
- Whether the algorithm is stable.
- Whether it is in-place.
