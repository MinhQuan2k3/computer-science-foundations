# Searching Algorithms

Implemented:

- Linear Search
- Iterative Binary Search
- Recursive Binary Search

| Algorithm | Requirement | Time |
|---|---|---:|
| Linear Search | None | O(n) |
| Binary Search | Sorted input | O(log n) |
| Recursive Binary Search | Sorted input | O(log n) |

Binary search is only valid when the search range is ordered.
